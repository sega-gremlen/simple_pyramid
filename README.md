# Простая Пирамида

Десктоп-программа для инженеров Сызранского РЭС. По заводскому номеру прибора учёта (ПУ) быстро
показывает данные из корпоративного ПО «Пирамида» — без долгого блуждания по веб-интерфейсу.

## Что умеет

- **Точка учёта** — тип счётчика, договор, место установки.
- **Показания** A+ / A− по зонам (TO, T1, T2); значение копируется кликом (с запятой — сразу в Excel).
- **Нагрузка** — состояние реле и лимит мощности.
- **Опрос прибора** — кнопка ↻ на «Показаниях» и «Нагрузке» запрашивает свежие данные, ✕ — отмена.
- **События** — журнал прибора в отдельном окне, фильтр «Только важные»; тревожные события
  (вскрытие и т. п.) подсвечиваются красной иконкой рядом с типом счётчика.
- **Маршруты связи** с автоматическим пингом.
- **Подневка** — просмотр показаний на начало суток и выгрузка в xlsx.
- **Почасовка** — выгрузка отчёта в xlsx.
- Автообновление: при выходе новой версии программа покажет, что изменилось, и обновится сама.

Сервер «Пирамиды» доступен только из корпоративной сети, поэтому с боевыми данными программа
работает только на рабочем ПК.

## Установка (для пользователей)

Скачать установщик последней версии со страницы
[Releases](https://github.com/sega-gremlen/simple_pyramid/releases) и запустить.
При первом запуске ввести логин и пароль от «Пирамиды» — пароль хранится в диспетчере учётных
данных Windows.

## Разработка

Нужны Windows, [uv](https://docs.astral.sh/uv/) и Python 3.13 (uv поставит его сам).

```bash
uv sync                                   # зависимости
uv run python -m simple_pyramid           # запуск против боевого сервера (рабочий ПК)
uv run python -m dev.run                  # запуск с эмулятором «Пирамиды» (работает дома)
uv run python -m dev.web_preview          # тот же интерфейс в браузере: http://127.0.0.1:8770
```

В эмуляторе подойдёт любой логин (пароль `wrong` — ошибка входа). Номера ПУ для проверки:
`000` — не найден, `111` — найдено несколько, `222` — без опросов, `333` — 3 маршрута,
`555` — реле отключено, `777` — тревожные события, `999` — долгий опрос с ошибкой,
любой другой — обычный прибор.

### Проверки

```bash
uv run ruff check . && uv run ruff format --check . && uv run mypy && uv run pytest --cov
uv run pre-commit install                 # один раз: проверки перед каждым коммитом
```

### Сборка

```bash
uv run pyinstaller simple_pyramid.spec --noconfirm    # → dist/simple_pyramid/
```

Установщик собирается Inno Setup из `installer/setup.iss`. Релиз делается кнопкой в GitHub:
**Actions → Release → Run workflow** — версия и список изменений считаются автоматически
по сообщениям коммитов ([Conventional Commits](https://www.conventionalcommits.org/ru/)).

## Устройство

```
src/simple_pyramid/
  api/        клиент HTTP-API «Пирамиды» и Pydantic-модели запросов/ответов
  domain/     чистая логика (выбор показаний, события, периоды)
  services/   сценарии: поиск ПУ, опросы, выгрузки
  desktop/    окно pywebview, мост JS ↔ Python, обновления, пароли
  ui/         HTML/CSS/JS интерфейса
dev/          эмулятор сервера и инструменты разработчика
tests/        unit- и интеграционные тесты
installer/    установщик Inno Setup
```

Подробности для разработчика (архитектура, правила, шпаргалка по API) — в [CLAUDE.md](CLAUDE.md).
